## 不应宣称已验证

- 空闲或无人订阅 Codex 会话能被外部通知自动唤醒。
- 全新会话中每次普通开发都必然隐式选择 Skill；已有会话自主选择和 loader 发现不是盲测。
- 正在运行时的真机断电或 Windows/WSL 重启；只验证了失效 boot ID 的恢复分支。
- Windows/macOS 原生后台监督和远程进程树管理。
- 同时强杀两个管理进程或不可中断内核 I/O 的清理。
- 任意后续副作用的恰好一次执行。

一次 queue 投递/消费实验只证明消息成功入队、目标活跃回合未消费；测试条目已清理。
运行成功的通知回调不代表模型被唤醒。
